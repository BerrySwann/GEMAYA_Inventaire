EDL v2 - architecture cible

Un seul code source : APK Android pour le terrain, site web pour le bureau - simulation a valider

Pile technique retenue

  • • SvelteKit 5 + TypeScript (un seul code)
  • • Capacitor pour produire l'APK Android
  • • Tailwind CSS + shadcn-svelte
  • • PostgreSQL 16 + Drizzle (migrations versionnees)
  • • Stockage objet compatible S3 pour les photos
  • • Gotenberg pour les PDF, Caddy + Docker sur un VPS

Ce que change l'APK

  • • Camera native, geolocalisation, dictee du systeme
  • • Donnees locales en SQLite : sous-sol sans reseau
  • • Installation sans magasin d'applications
  • • Le keystore est vital : perdu, plus de mise a jour
  • • Mise a jour a integrer (controle de version dans l'appli)
  • • iPhone non couvert : a trancher avant de coder

IA : prevue, deconnectee

  • • Table des champs : source, confiance, modele, statut
  • • L'IA propose, l'humain valide : aucune ecriture directe
  • • Photo d'origine conservee comme preuve
  • • Auto-heberge (donnees chez toi) ou API (immediat)
  • • 600 photos par site = quelques euros en API
  • • A prevoir maintenant, a developper en phase 5

Decoupage et charge

  • • Phase 1 : socle donnees et comptes (5 a 8 j)
  • • Phase 2 : terrain + hors ligne (10 a 15 j)
  • • Phase 2b : APK, signature, distribution (3 a 5 j)
  • • Phase 3 : bureau, revue, comparaison (8 a 12 j)
  • • Phase 4 : rapports PDF (5 a 8 j)
  • • Phase 5 : IA + phase 6 reprise : 11 a 17 j
  • • Total : 45 a 69 jours de developpement
